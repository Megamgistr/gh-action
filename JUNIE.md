# Project Environment and Test Instructions

- **Programming Language:** TypeScript (builds to Node.js/JavaScript, uses Bun runtime)
- **Primary Package Manager:** Bun (v1.3+)

## How to Install the Environment
```bash
bun install --no-interactive
bun run build
```

## How to Activate the Environment
- No activation needed. Ensure the `bun` command is available in your shell.

## How to Run Tests
- No tests are currently defined in the project (`test` script is not present in package.json).
- If tests are added in the future, run them with:
  ```bash
  bun run test
  ```
