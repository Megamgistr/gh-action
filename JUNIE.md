# JUNIE Environment Setup Guide

- **Programming language:** TypeScript (using TypeScript 5.5, compiled to Node.js)
- **Primary package manager:** Bun

## Install Dependencies
```bash
bun install --no-progress --no-save
```

## Environment Activation
No activation required; Bun does not use virtual environments.

## Build/Compile Project
```bash
bun run build
```

## Run Tests
No automated/project tests are defined.

---
This project builds with Bun and TypeScript. The build process completes successfully and there are currently no test scripts to run.
